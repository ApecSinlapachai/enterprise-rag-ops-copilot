# คู่มือมาตรฐานการเพิ่มและเพิกถอนสิทธิ์ผู้ใช้งานระดับองค์กร

ขั้นตอนมาตรฐานนี้ใช้สำหรับผู้ดูแลระบบ (Workspace Admin) และทีม `l1_support` เพื่อควบคุมการเข้าถึงข้อมูลอย่างปลอดภัย

## การกำหนดสิทธิ์ตามบทบาท (Role-Based Access Control - RBAC)

แพลตฟอร์มกำหนดสิทธิ์ผู้ใช้งานออกเป็น 4 บทบาทหลักตามหลัก Least Privilege:

1. **Org Owner**: สิทธิ์สูงสุดในการจัดการสัญญา การเงิน การตั้งค่า SSO และโอนย้ายความเป็นเจ้าขององค์กร
2. **Workspace Admin**: สิทธิ์เพิ่ม/ลบสมาชิก อัปโหลดเอกสารความรู้ และสร้าง API Keys
3. **Ops Analyst**: สิทธิ์ค้นหาข้อมูล RAG Copilot และจัดการตั๋วแจ้งปัญหา Ticket Triage
4. **Read-Only Auditor**: สิทธิ์ดูประวัติ Audit Logs และผลประเมิน Golden Eval Scorecard เท่านั้น

### ขั้นตอนการเพิ่มผู้ใช้งานใหม่ (Onboarding)

ผู้ดูแลระบบเชิญผู้ใช้งานใหม่ผ่านอีเมลองค์กร โดยลิงก์เชิญมีอายุ **48 ชั่วโมง** และสำหรับองค์กรที่ใช้แพ็กเกจ Enterprise (`SKU-ENT-ANNUAL`) แนะนำให้เปิดใช้งานการ Provision อัตโนมัติผ่าน SAML 2.0 / OIDC

## ขั้นตอนการเพิกถอนสิทธิ์พนักงานที่ลาออกเร่งด่วน (Emergency Offboarding)

เมื่อมีพนักงานลาออกหรือสิ้นสุดสัญญาจ้าง ทีมดูแลระบบขององค์กร `ORG-DEMO-01` ต้องดำเนินการดังนี้:

- ยกเลิก Session ที่ยังใช้งานอยู่ (Revoke Active Sessions) และเพิกถอน API Keys ส่วนบุคคลภายใน **15 นาที** สำหรับบัญชีระดับ `Org Owner` หรือ `Workspace Admin`
- โอนย้ายสิทธิ์ความเป็นเจ้าของเอกสารและ Webhook Endpoints ไปยังผู้ดูแลระบบคนใหม่ก่อนกดปิดใช้งานบัญชี (Deactivate User)
- หากองค์กรไม่สามารถเข้าถึงบัญชี `Org Owner` ได้ ให้ส่งคำร้องฉุกเฉินถึงทีม `security_ops` พร้อมหนังสือรับรองจากผู้มีอำนาจลงนาม

## การตรวจสอบสิทธิ์รายไตรมาส (Quarterly Access Review)

- บังคับใช้การยืนยันตัวตนหลายปัจจัย (**MFA 100%**) สำหรับผู้ใช้งานที่มีสิทธิ์ `Org Owner` และ `Workspace Admin` ทุกคน
- องค์กรควรส่งออกรายงานรายชื่อผู้ใช้งานและ API Keys ที่ไม่เคลื่อนไหวเกิน **90 วัน** เพื่อเพิกถอนสิทธิ์เป็นประจำทุกไตรมาส
