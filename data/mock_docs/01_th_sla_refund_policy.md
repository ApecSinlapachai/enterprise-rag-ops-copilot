# นโยบายการรับประกันระดับการให้บริการ (SLA) และการขอคืนเงิน

เอกสารนี้กำหนดมาตรฐานความพร้อมใช้งานของระบบ (Uptime SLA) และเกณฑ์การชดเชยเครดิตค่าบริการสำหรับลูกค้าองค์กรบนแพลตฟอร์ม Enterprise RAG Ops Copilot

## เป้าหมายความพร้อมใช้งานของระบบ (Uptime SLA Commitment)

บริษัทรับประกันความพร้อมใช้งานรายเดือน (Monthly Uptime Percentage) ของ Production API และ Web Console ตามระดับแพ็กเกจดังนี้:

- **Enterprise Tier (`SKU-ENT-ANNUAL`)**: รับประกันความพร้อมใช้งานไม่ต่ำกว่า **99.95%** ต่อรอบบิลรายเดือน (Downtime สูงสุดไม่เกิน 21.9 นาที/เดือน)
- **Pro Tier (`SKU-PRO-MONTHLY`)**: รับประกันความพร้อมใช้งานไม่ต่ำกว่า **99.50%** ต่อรอบบิลรายเดือน
- **Starter Tier**: ไม่มีข้อผูกพัน SLA เชิงพาณิชย์ (Best-effort 99.00%)

การบำรุงรักษาตามแผน (Scheduled Maintenance) ที่แจ้งล่วงหน้าอย่างน้อย 72 ชั่วโมง หรือเหตุสุดวิสัยภายนอกเครือข่ายของบริษัท จะไม่ถูกนำมาคำนวณเป็น Downtime

## เกณฑ์การคำนวณเครดิตเงินคืน (SLA Service Credit Tiers)

หากความพร้อมใช้งานในรอบบิลใดต่ำกว่าเกณฑ์ SLA ลูกค้าองค์กร (เช่น `ORG-DEMO-01`) มีสิทธิ์ขอรับเครดิตค่าบริการคืนเข้าบัญชีในรอบบิลถัดไป หรือขอคืนเงินกรณีปิดรอบบิลรายปีตามสัดส่วนดังนี้:

| ช่วงความพร้อมใช้งานรายเดือน (Monthly Uptime) | อัตราเครดิตชดเชย (Service Credit) | หมายเหตุการอนุมัติ |
| :--- | :--- | :--- |
| `99.00% - 99.94%` (Enterprise) | **10%** ของค่าบริการรายเดือน | ตรวจสอบจาก Telemetry Log |
| `95.00% - 98.99%` | **25%** ของค่าบริการรายเดือน | ต้องแนบ `incident_id` |
| ต่ำกว่า `95.00%` | **50%** ของค่าบริการรายเดือน | อนุมัติระดับ Head of Ops |

### ตัวอย่างการคำนวณสำหรับใบแจ้งหนี้

หากองค์กร `ORG-DEMO-01` ได้รับผลกระทบจากเหตุระบบล่ม `ERR-503` จนทำให้ Uptime ประจำเดือนลดลงเหลือ `98.80%` ลูกค้าสามารถอ้างอิงเลขที่ใบแจ้งหนี้ เช่น `INV-2026-0091` เพื่อขอรับเครดิตชดเชยจำนวน **25%** ของยอดค่าบริการในรอบบิลนั้น

## ขั้นตอนและระยะเวลาการยื่นขอคืนเงิน (Refund & Credit Claim Procedure)

1. ผู้ดูแลระบบขององค์กรต้องส่งคำร้องผ่าน Support Portal หรืออีเมลถึงทีม `billing_ops` ภายใน **15 วันทำการ** นับจากวันสิ้นรอบบิลที่เกิดเหตุ
2. ระบุข้อมูลประกอบคำร้อง ได้แก่ รหัสองค์กร (`ORG-DEMO-01`), เลขที่ใบแจ้งหนี้ (`INV-2026-0091`), และรหัสเหตุการณ์ขัดข้อง (`INC-2026-0412`) พร้อมช่วงเวลาที่ได้รับผลกระทบ (UTC/ICT)
3. ทีม `billing_ops` จะตรวจสอบบันทึกการทำงานของระบบ (System Telemetry) และแจ้งผลการอนุมัติภายใน **7 วันทำการ**
4. เครดิตค่าบริการที่อนุมัติแล้วจะถูกหักออกจากใบแจ้งหนี้รอบถัดไปโดยอัตโนมัติ (ไม่สามารถแลกเป็นเงินสดได้ เว้นแต่กรณียกเลิกสัญญาจากเหตุ SLA ต่ำกว่า 95.00% ติดต่อกัน 2 รอบบิล)
